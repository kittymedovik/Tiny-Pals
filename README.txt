TINY WINS CLUB - install on your phone

This folder is a complete web app (a "PWA"). It has to be hosted at an https address once, then you add it to your home screen.

Easiest free options (pick one):
1. Netlify Drop: go to app.netlify.com/drop, drag this whole folder onto the page. You get a link in about 10 seconds.
2. Cloudflare Pages or GitHub Pages: upload these files to a new project/repo and turn on hosting.

Then on your phone, open that link:
- iPhone: open in Safari, tap Share, then Add to Home Screen.
- Android: open in Chrome, tap the menu (three dots), then Install app (or Add to Home screen).

It opens full screen like a normal app and works offline after the first load (sounds and fonts are cached too).

Your progress is stored on the phone. The version inside Claude and the installed app keep separate progress. To move progress: in the old one tap the gear, Show backup, copy the text; in the new one tap the gear, paste it, Restore from text.

Want a real App Store / Play Store build? Take your hosted link to pwabuilder.com, which can package it for Android (and iOS with a developer account).
